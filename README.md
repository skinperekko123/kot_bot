# 🐾 Animal Classifier Bot

Telegram-бот на базе искусственного интеллекта, который умеет определять животных по их фотографиям.

---

## 📌 Описание

**kot_bot** — это интерактивный Telegram-бот, предназначенный для распознавания животных на изображениях. 

Пользователь отправляет боту фотографию (например, с котом, собакой или другим животным), а бот с помощью предварительно обученной нейросети классифицирует изображение и выдает ответ с названием животного и уровнем уверенности модели.

### 💡 Как это работает:
1. Пользователь отправляет изображение в чат с ботом.
2. Бот предварительно обрабатывает изображение (изменяет размер, нормализует пиксели под формат модели).
3. Модель глубокого обучения (Computer Vision) анализирует картинку и делает предсказание.
4. Бот отправляет результат классификации обратно пользователю.

---

* **Язык программирования:** Python 3.10+
* **Библиотека бота:** `pyTelegramBotAPI` (Telebot)
